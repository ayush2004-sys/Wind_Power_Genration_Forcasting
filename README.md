# Wind_Power_Genration_Forcasting
Forecasting wind power generation is crucial for optimizing renewable energy integration into smart grids. This project focuses on building machine learning and deep learning models to predict wind power output based on meteorological and historical generation data.
📌 Project Overview
⚡ Goal: Improve prediction accuracy of wind power generation
🌍 Impact: Helps grid operators balance supply-demand, reduce reliance on fossil fuels, and enhance renewable energy efficiency
🧠 Approach: Data preprocessing, feature engineering, machine learning models (Random Forest, XGBoost) and deep learning models (LSTMs, Transformers)
⚙️ Installation
Clone the repository:
git clone https://github.com/ayush/Wind_Power_Genration_Forcasting.git
cd Wind_Power_Genration_Forcasting
Install dependencies:
pip install -r requirements.txt
