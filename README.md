# 🌬️ Wind Power Generation Forecasting  

Forecasting wind power generation is crucial for optimizing renewable energy integration into smart grids.  

## 📌 Project Overview  

- ⚡ **Goal:** Improve prediction accuracy of wind power generation  
- 🌍 **Impact:** Helps grid operators balance supply-demand  
- 🧠 **Approach:** Data preprocessing, feature engineering, ML & DL models
